# CI/CD Zero to Production
A production-style CI/CD learning project built completely locally on macOS using:

- GitHub Actions
- Jenkins
- Docker
- Kubernetes
- Helm
- Kind

## Goals

- Learn CI pipelines
- Learn CD pipelines
- Learn Kubernetes deployments
- Learn production DevOps practices
- Build a portfolio-grade project
